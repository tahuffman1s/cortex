The first release of Cortex: find the Windows (SMB) shares on your network's file servers and keep them as network drives, on any Linux desktop.

- Suggested servers: the ones your drives are on, the DNS domains your network or VPN hands out (a domain lists its DFS folders), and the file servers announced on the local network
- A server's shares with their descriptions, hidden ones (`setups$`) included and Windows' own (`C$`, `ADMIN$`, `IPC$`, `print$`) left out, or a share path pasted straight in
- One sign-in for every share, the password kept in your keyring (Secret Service); a Kerberos ticket is used first when there is one
- A new password is tried once before it's saved, and a refused one is never retried, so a typo can't lock a domain account
- Drives connect on demand or at login, and show up in the file manager sidebar
- No root and no fstab: connections go through GIO/GVfs, so it also runs as a Flatpak

Needs Python 3.10+, PyGObject, GTK 4, libadwaita 1.5+ and GVfs's SMB backend (`gvfs-smb` / `gvfs-backends`); libsecret is optional. The README lists each distribution's packages.

Install from the tarball:

```sh
tar xf cortex-0.1.0.tar.xz && cd cortex-0.1.0
meson setup build --prefix=/usr/local
sudo meson install -C build
```
