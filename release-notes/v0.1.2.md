Fixes the AppImage not starting on systems that don't keep the usual shared libraries where the loader looks, such as NixOS with nix-ld:

```
python3: error while loading shared libraries: libexpat.so.1: cannot open shared object file
```

The AppImage now carries every library it needs except glibc, the C++ runtime and the graphics drivers, and its own copy of the MIME database (without which icons could show as broken images). The build checks that nothing else is left to the system.

On NixOS, Cortex needs `programs.nix-ld.enable = true;` (or `appimage-run`) to start and `services.gvfs.enable = true;` to open shares; Plasma doesn't turn GVfs on by itself.

```sh
chmod +x Cortex-0.1.2-x86_64.AppImage
./Cortex-0.1.2-x86_64.AppImage
```
